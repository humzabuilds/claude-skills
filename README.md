## Install in the Claude app or claude.ai
1. Settings, then Capabilities, and turn on Skills.
2. Click "Upload skill" and pick the zip you downloaded.

## Install in Claude Code
Unzip it into `~/.claude/skills/` so you end up with `~/.claude/skills/<skill-name>/SKILL.md`.

## Use it
Just ask for the thing. Say "break this down", "write this reply for me", "lock it in", "build me a landing page" or "edit this video".
